# Graphic Design

This folder contains the graphic design work I completed as part of my Oasis Infobyte Internship Program (OIBSIP).

The tasks gave me an opportunity to work on different types of visual content and improve my understanding of layout, typography, color, branding, and visual communication.

## Projects

- Posters & Fliers
- Logo Design
- Business Card Design
- Infographic
- Magazine/Brochure Design

## Tools Used

- Canva
- Figma

## Image Sources

Some of the designs use images found online for design and visual practice. These images are not my original work and are used only as part of the design projects.

Sources used across the projects include Unsplash, Pinterest, and other publicly available online sources. Original image credits have been included wherever the source could be identified.

## Folder Structure

Each project is organized in its own folder and contains the final design files, relevant project files, and documentation.
